# Бэкенд WebLarek.

## Используемые технологии и решения

- Typescript в качестве основного языка проекта
- Mongodb и ODM Mongoose для хранения данных пользователей
- Node.js в качестве среды выполнения

Перед отправкой работы на проверку убедитесь что она соответствует требованиям проектной работы

## Запуск backend

Для работы проекта необходимы Node.js, npm и MongoDB.

Перейдите в папку backend и установите зависимости:


cd backend
npm ci


Создайте файл `.env` на основе `.env.example` и заполните его:


PORT=3000
DB_ADDRESS=mongodb://127.0.0.1:27017/weblarek
ORIGIN_ALLOW=http://localhost:5173


Запустите MongoDB, затем запустите сервер:


npm run start


Сервер будет доступен по адресу http://localhost:3000.

### Команды

- `npm run start` — запуск сервера.
- `npm run dev` — запуск с автоматической перезагрузкой.
- `npm run build` — сборка проекта.
- `npm run lint` — проверка кода.
- `npm run lint:fix` — исправление ошибок линтера.

### API

- `GET /product` — получение товаров.
- `POST /product` — создание товара.
- `POST /order` — оформление заказа.

Изображения хранятся в папке `src/public/images` и доступны по пути `/images/`.

Логи запросов записываются в `request.log`, логи ошибок — в `error.log`.
